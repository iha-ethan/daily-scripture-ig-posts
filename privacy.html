Privacy Policy

Daily Scripture Posts · Last updated November 1, 2026

Daily Scripture Posts is a small automated tool that publishes one Bible verse image each day to the Instagram account @inhisarms.life. It is operated by the owner of that account for their own use only.

What information the app uses

The app only accesses the Instagram account it was set up for, using the permissions instagram_business_basic and instagram_business_content_publish. It uses the account's ID and an access token solely to publish posts to that account.

The app does not collect, read, or store any information about other Instagram users, followers, comments, or messages. It has no sign-up, no login for the public, no cookies, and no analytics.

How information is stored

The access token is stored as an encrypted secret in the owner's GitHub repository and is used only by the automated posting job. It is never shared, sold, or given to anyone else.

Third-party services

To create each post, the app requests verse text from the NLT API (Tyndale House Publishers) and a background photo from Unsplash. These requests contain no personal information.

Data deletion

Because the app stores no data about anyone other than the account owner, there is no user data to delete. The owner can revoke the app's access at any time in Instagram under Settings → Website permissions → Apps and websites, and delete the stored token from GitHub. To ask about data deletion, email ethan@inhisarms.life.
